## 🚀 Sobre o Projeto

Landing page institucional da **Akylla Solutions** — uma plataforma web moderna que apresenta os serviços de automação inteligente, integrações via API, sistemas SaaS e IA aplicada para negócios.

O site foi desenvolvido como um **single-page application (SPA)** em React, com design system próprio, animações suaves e foco total em performance e experiência do usuário.

### ✨ Funcionalidades

- **Navbar responsiva** com scroll spy e menu mobile
- **Seção Hero** com gradiente animado e cards flutuantes
- **Grid de Problemas** que resolvemos com automação
- **Catálogo de Soluções** com cards interativos
- **Portfólio de Projetos** com filtros e badges de tecnologia
- **Sobre** com stack tecnológico exibido em grid
- **Formulário de Contato** com feedback visual
- **Footer** completo com navegação e links

## 🛠️ Stack Tecnológica

| Tecnologia | Uso |

## 🏁 Como Executar Localmente

```bash
# Clone o repositório
git clone https://github.com/Tanattos18/Akylla-Solutions.git

# Acesse o diretório
cd Akylla-Solutions

# Instale as dependências
npm install

# Inicie o servidor de desenvolvimento
npm run dev
```

> ⚠️ **Nota:** Certifique-se de ter o [Node.js](https://nodejs.org) instalado. O projeto utiliza Vite ou Create React App como bundler (adicione o `package.json` correspondente).
